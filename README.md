# TCC – Segurança da Informação na Formação Acadêmica

Este repositório é utilizado para a organização, versionamento e reprodutibilidade da análise de dados do Trabalho de Conclusão de Curso desenvolvido no curso de **Ciência da Computação**.

O projeto investiga a relação entre **conhecimento técnico**, **percepção de risco** e **comportamentos digitais** relacionados à segurança da informação entre estudantes universitários de cursos de tecnologia.

---

## 🎯 Objetivo do Projeto

Analisar possíveis lacunas entre a formação acadêmica em tecnologia e as práticas reais de segurança da informação adotadas pelos estudantes no cotidiano, identificando discrepâncias entre o conhecimento declarado e os comportamentos efetivamente observados.

---

## 📚 Contexto do Estudo

O estudo é baseado em dados coletados por meio de um **questionário estruturado**, aplicado a estudantes dos cursos de **Ciência da Computação** e **Engenharia de Software**.

A análise considera os seguintes eixos teóricos:

- Conhecimento técnico em segurança da informação  
- Percepção de risco no ambiente digital universitário  
- Conscientização e hábitos de segurança  
- Comportamentos digitais inseguros

## 🔎 Metodologia de Análise (Visão Geral)

A análise dos dados segue as seguintes etapas:

1. Preparação e limpeza dos dados coletados  
2. Recodificação de variáveis e escalas  
3. Construção de índices analíticos  
4. Análise descritiva dos dados  
5. Cruzamento entre variáveis centrais  
6. Análise qualitativa das respostas abertas  

Os procedimentos são realizados de forma incremental, com versionamento a cada etapa concluída.

---

## 🔐 Considerações Éticas

- Os dados analisados são **anônimos**  
- Informações sensíveis (como e-mails de contato) são removidas antes da análise  
- Os dados brutos não são versionados neste repositório  
- O repositório é **privado** e destinado exclusivamente a fins acadêmicos
